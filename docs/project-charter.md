# Project Charter

## Objective
Build an AI-powered job search assistant specialized in BI, Power BI, Data Analytics, SQL and Data Engineering positions.

## Scope
- Resume optimization
- Job matching
- Automatic applications
- Interview preparation

## Initial MVP
- A local-first browser workspace for resume-to-job-description matching and application tracking.
- Dice and Monster search links, with listings added by the user.
- User-configurable match threshold and daily application limit.
- This first version does not upload personal data, scrape job boards, or submit applications automatically.
